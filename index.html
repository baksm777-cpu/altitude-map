    선택 지점

    지도에서 아무 곳이나 누르거나 주소를 검색해 보세요. 적용되는 제한 표면과 고도지구를 모두 나열하고, 가장 낮은 값을 최종 제한으로 보여줘요.

    제한 높이 (색상 범례)

    표시 레이어

    바로 가기

    이 데모에 대해

    비행장 제한표면은 ICAO 기준(민간)과 군 비행안전구역 기준(군·민군겸용)의 표준 치수를 활주로 하나로 단순화해 계산했어요. 높이는 비행장 표고 기준이고, 고도지구는 지표 기준이에요. 고도지구 경계와 높이는 위치를 보여주기 위한 예시예요. 실제 인허가 판단에는 토지이음(eum.go.kr) 토지이용계획과 관할 기관 협의 결과를 확인하세요.

    카카오 지도 앱 키가 필요해요

    1. Kakao Developers에서 애플리케이션 추가
    2. 앱 설정 → 플랫폼 → Web에 이 페이지 주소를 등록 (지금 주소: )
    3. 제품 설정 → 카카오맵을 사용 설정 ON
    4. 앱 키의 JavaScript 키를 아래에 붙여 넣기
